## 🏗️ Core Architecture
Echo-Lens implements a robust **Neural Diagnostic Layer** capable of processing web DOM structures and identifying accessibility vulnerabilities in real-time.

### Key Technical Pillars:
*   **Neural Scan Console**: Provides high-fidelity live feedback during the auditing process.
*   **Lighthouse Orchestration**: Native integration with Google PageSpeed Insights for industry-standard scoring.
*   **Guardian Protocol**: Automated synthesis of exportable JS payloads to patch identified vulnerabilities.
*   **Heuristic Fallback**: A resilient backup engine that ensures system uptime during API rate-limiting or network latency.

## 🛠️ Tech Stack
*   **Diagnostic Engine**: Vanilla JavaScript (ES6+) with optimized asynchronous orchestration.
*   **API Layer**: Google PageSpeed Insights (Lighthouse) for deep compliance auditing.
*   **UI Architecture**: Glassmorphic CSS3 with custom cubic-bezier animations and radial glows.
*   **Visualization**: Canvas-based 3D Particle Engine for diagnostic feedback.

## 🚀 Getting Started

### Prerequisites
*   A modern web browser with ES6 support.
*   Zero external dependencies (Pure Vanilla Implementation).

### Installation
1.  **Clone the repository**:
    ```bash
    git clone https://github.com/ayanlogix/echo-lens.git
    ```
2.  **Navigate to the project directory**:
    ```bash
    cd echo-lens
    ```
3.  **Open `index.html`** in your browser.
